# hello-git

这是我的第一个 Git 仓库，用来练习 Git 的基本操作。

## 这个仓库是干什么的

- 演示「工作区 → 暂存区 → 本地仓库」的三区模型
- 练习 `add` / `commit` / `log` / `status` 四个命令
- 之后会推送到 GitHub，练一次完整的 `push`

## 学习笔记

### 三区模型

```
工作区（你正在编辑的文件）
   ↓  git add
暂存区（准备提交的清单）
   ↓  git commit
本地仓库（有历史记录了）
   ↓  git push
GitHub 远程仓库
```

### 为什么改完文件还要 add 一次

因为 Git 允许你「挑着提交」。你改了 5 个文件，可以只把其中 2 个放进暂存区先提交，
剩下 3 个等改完再提交。如果没有暂存区这一步，就只能每次全提交，没法拆分。
